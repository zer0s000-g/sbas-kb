# KASS

## Scope status

This is a draft system note built from references already present in the vault.

Boundary:

## Working definition

Within the current vault, KASS is treated as the South Korean regional implementation of satellite-based augmentation used to support aviation operations, especially SBAS-enabled approach capability.

## Provisional in-vault profile

The current vault describes KASS as having:

- Korean territory coverage
- operational status following certification by national authorities
- development with Thales Alenia Space as prime contractor
- SBAS technology for GPS positioning improvement

These profile elements are still provisional until supported by dedicated source extraction.

## Relationship to civil aviation use

In current vault structure, KASS matters because it represents:

- a regional SBAS implementation in Northeast Asia
- a potential interoperability partner for MSAS and other regional systems
- a reference point for ASEAN regional SBAS analysis

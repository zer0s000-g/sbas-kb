# MSAS

## Scope status
This is a draft system note built from references already present in the vault.

Boundary:
- This note does not verify regional performance figures, dates, coverage claims, or interoperability statements against external source material.
- It consolidates what the vault currently says about MSAS and marks those statements as provisional where needed.

## Working definition
Within the current vault, MSAS is treated as the Japanese regional implementation of satellite-based augmentation with particular relevance to oceanic and terminal aviation operations.

## Provisional in-vault profile
The current vault describes MSAS as having:
- Japan-centered coverage with some Pacific relevance
- operational maturity within the regional SBAS landscape
- strong association with oceanic and terminal operations
- comparative relevance in inter-regional compatibility discussion, especially relative to [[EGNOS]]

These profile elements are still provisional until supported by dedicated source extraction.

## Current claims already present elsewhere in the vault
The following claims appear in existing notes and should be treated as provisional until verified:
- MSAS supports oceanic and terminal operations
- MSAS covers Japan and selected Pacific regions
- MSAS participates in draft compatibility framing with [[EGNOS]]
- MSAS is one of the major mature regional SBAS implementations

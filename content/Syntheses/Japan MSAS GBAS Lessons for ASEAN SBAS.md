# Japan MSAS GBAS Lessons for ASEAN SBAS

## Scope status

This note uses the GIPTA Japan update as a comparator. It does not duplicate the [[MSAS]] system note or the [[GBAS-Approach-Procedure]] note.

## Comparator value

Japan’s MSAS and GBAS experience gives ASEAN planners a nearby operational and institutional reference point: existing SBAS operation, GBAS deployment at Haneda, avionics/equipage considerations, and the separation between system capability and procedure/service adoption.

## ASEAN lessons to treat cautiously

- an operational reference system helps training, but ASEAN geography and ionospheric conditions require local evidence
- GBAS and SBAS can be complementary rather than mutually exclusive
- procedure publication, equipage, and operational approval matter as much as infrastructure
- service-area expansion is one possible model, but not automatically the selected ASEAN model

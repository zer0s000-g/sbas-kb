# WAAS vs EGNOS

## Scope status
This is a draft comparison note built from references already present in the vault.

Boundary:
- It does not verify coverage, maturity, performance, certification, or interoperability claims against external source material.
- It organizes what the vault currently says about [[WAAS]] and [[EGNOS]] and marks broad regional claims as provisional.

## Why compare them
Within the current vault, [[WAAS]] and [[EGNOS]] are the two most developed regional SBAS examples.

They currently function as:
- the primary U.S. regional SBAS reference
- the primary European regional SBAS reference
- the first pair suitable for regional comparison without overextending the current evidence base

## Current in-vault comparison pattern
The vault currently suggests the following comparative framing:
- [[WAAS]] is associated with U.S. coverage, operational maturity, and LPV-related civil-aviation use
- [[EGNOS]] is associated with European coverage, operational maturity, and LPV/terminal-area aviation use
- draft interoperability language links them in transatlantic context

These statements are provisional until directly sourced.

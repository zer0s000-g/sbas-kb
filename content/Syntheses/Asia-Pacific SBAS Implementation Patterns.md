# Asia-Pacific SBAS Implementation Patterns

## Scope status

This is a draft synthesis note built from references already present in the vault.

Boundary:

- It does not verify regional deployment, performance, interoperability, or operational-benefit claims against external source material.
- It compares current in-vault treatment of Asia-Pacific regional systems and marks broad claims as provisional.

## Current in-vault pattern

The vault currently suggests:

- [[MSAS]] is framed around Japan, Pacific relevance, and oceanic/terminal operations
- [[GAGAN]] is framed around India, surrounding-region relevance, and a growing/cost-effective implementation profile
- Asia-Pacific appears in the civil-aviation MOC as a region of gradual SBAS rollout

These statements are synthesis and remain provisional.

## Comparison dimensions currently present in the vault

### Geographic emphasis

- [[MSAS]]: Japan-centered with Pacific/oceanic relevance
- [[GAGAN]]: India-centered with surrounding-region relevance

### Operational framing

- [[MSAS]]: stronger emphasis on oceanic and terminal operations
- [[GAGAN]]: stronger emphasis on regional rollout and implementation growth

### Maturity framing

- [[MSAS]] currently appears in the vault as one of the more mature regional systems
- [[GAGAN]] currently appears as a growing regional implementation

### Open interoperability layer

The current vault contains more developed interoperability language for WAAS/EGNOS than for Asia-Pacific systems.
That means Asia-Pacific comparison remains structurally useful but source-light.

In current vault structure, Asia-Pacific SBAS implementation patterns matter because they may affect:

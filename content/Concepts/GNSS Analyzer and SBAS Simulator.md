# GNSS Analyzer and SBAS Simulator

## Definition status
This note captures a GIPTA implementation toolchain concept. It does not replace formal SBAS ground-segment architecture descriptions.

## Working definition
A GNSS analyzer / SBAS simulator setup collects and analyzes GNSS observations, supports ionospheric-environment assessment, and simulates SBAS messages as part of pre-operational feasibility and training.

## GIPTA-specific role
The GIPTA documents present the analyzer/simulator as a way to build regional evidence before selecting or certifying an ASEAN SBAS implementation pathway.

## Aviation implications
The toolchain is relevant because low-latitude ionospheric behavior affects integrity confidence, service availability, and the feasibility of safe SBAS operation.

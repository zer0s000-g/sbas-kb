# ASEAN ABAS Concept

## Definition status
This note exists only because one GIPTA source filename says “ASEAN-ABAS” while extracted title text and content point toward “Concept of ASEAN-SBAS project.”

## Working interpretation
At this stage, “ASEAN ABAS” should not be treated as a settled program name or separate architecture. The usable content in the source concerns staged ASEAN SBAS implementation: ADB TA, guidelines, FIR-level feasibility, master planning, GNSS environment analysis, testbed work, and capacity building.

## Boundary
Do not use this note to claim that ASEAN has a defined ABAS system. Keep the ambiguity visible until the original presentation metadata is verified.

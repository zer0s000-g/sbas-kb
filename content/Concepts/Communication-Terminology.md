# 📡 Communication Terminology

## 📊 **Core Definitions**

- **Data Link**: Digital communication channel for exchanging information
- **Message Format**: Structured data packet definition for information exchange
- **Protocol**: Set of rules governing communication between systems
- **Broadcast**: One-to-many communication without acknowledgment
- **Polling**: Request-response communication pattern

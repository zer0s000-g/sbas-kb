# Source - APANPIRG and CNS SG SBAS References

## Scope of this note

This is a starter source scaffold for APANPIRG and CNS Sub-Group material that may support or narrow claims in the ASEAN SBAS governance branch.

Boundary:

- This is not a completed extraction.
- It does not prove that APANPIRG or CNS SG has endorsed an ASEAN SBAS program.
- It exists to separate broad APAC governance references from the narrower GBAS/SBAS forum references already captured in [[Source - ICAO APAC GBAS-SBAS Implementation Forums]].

## Why this source note matters

The current governance note uses APANPIRG and CNS SG as likely regional planning layers.
That claim is plausible, but still too broad until tied to identifiable records showing whether SBAS appears as:

- a direct planning topic
- a CNS modernization subtopic
- a procedure or implementation issue
- or only an adjacent background theme
